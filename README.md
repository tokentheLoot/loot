# theLoot (LOOT)

**theLoot (LOOT)** es un token ERC‑20 diseñado para impulsar el comercio digital descentralizado y la autenticidad de la propiedad en la red Ethereum.

- **Token Address:** [0x6d97F12bBE1fC340B608d747eF89e1C3C7e51f82](https://etherscan.io/token/0x6d97F12bBE1fC340B608d747eF89e1C3C7e51f82)
- **Logo:** ![logo](https://raw.githubusercontent.com/tokentheLoot/loot/main/logo.png)

## Descripción
theLoot busca explorar nuevas formas de interacción entre creadores, usuarios y activos digitales. Una vez completadas las actualizaciones en Etherscan, se ejecutará `renounceOwnership()` para asegurar la transparencia y evitar cualquier sospecha de “honeypot”.
